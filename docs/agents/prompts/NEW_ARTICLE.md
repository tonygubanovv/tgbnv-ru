# Запрос для Codex, Qoder или другого агента на новую статью

Я приложил Markdown-экспорт из Google Docs и, если нужно, изображения. Опубликуй это как новую статью в моём Astro-блоге строго по `AGENTS.md` и `docs/agents/specs/CONTENT_AND_SEO.md`. Исправь техническую разметку без переписывания смысла, добавь метаданные, краткое описание, категорию, теги, SEO, корректные alt, внутренние ссылки с учётом `import.meta.env.BASE_URL`. Не придумывай факты и результаты. Сначала покажи мне, что получилось, запусти `npm run check`, `npm run build`, `npm run smoke`. Не отправляй на GitHub без моего отдельного разрешения.

Для каждой статьи обязательно создать самостоятельную обложку с помощью imagegen по `docs/agents/prompts/BLOG_COVER_STYLE.md` и двум референсам из `docs/guides/BLOG_COVERS.md`. Нельзя повторять сюжет и композицию предыдущей картинки; стиль и качество рендера — единые. Подключить обложку через `cover` и проверить её в карточке и статье. Адрес электронной почты в ссылках показывать буквально, из общего конфига, без текста «Написать на почту».


Текст положить в `content/blog/<slug>/index.md`, обложку и иллюстрации — рядом в ту же папку. `summary` задаёт вступление и описание карточки; SEO-title, description и необязательные keywords задать только строкой `/blog/<slug>/` в `content/seo.md`. Теги берутся из `blogTags` в `src/config/site.ts`: отдельной страницы у темы нет, она только фильтрует `/blog/`, так что новая строка в таблице для неё не нужна.
